DIGITAL IMAGE PROCESSING (DIP) ASSIGNMENT

FILES
-----
1. huffman_coding.py
   Huffman coding example using the text "ABRACADABRA".
   No image is required.

2. arithmetic_encoding.py
   Arithmetic encoding example using the text "ABRACADABRA".
   No image is required.

3. image_filtering.py
   Applies different image kernels/filters to image.jpg.

4. image.jpg
   Sample image included for the image filtering program.

INSTALLATION
------------
Open a terminal in this folder and run:

pip install numpy opencv-python matplotlib pillow

RUNNING THE PROGRAMS
--------------------
python huffman_coding.py
python arithmetic_encoding.py
python image_filtering.py

IMPORTANT
---------
Keep image.jpg in the same folder as image_filtering.py.
The image filtering program saves the filtered images and a
filter_results.png comparison image in this folder.

NOTE
----
Huffman and arithmetic examples encode text symbols, while the
filtering program processes the supplied sample image.
